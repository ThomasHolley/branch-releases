# Branch

Branch est un terminal pour Mac avec un navigateur de fichiers qui suit votre travail : dossier courant et statut git, session Claude Code, serveur de développement, SSH, éditeur…

Ce dépôt contient uniquement les **installeurs** et les fichiers de **mise à jour automatique** de Branch.

## Télécharger

**[Télécharger Branch pour Mac](https://github.com/ThomasHolley/branch-releases/releases/latest/download/Branch.dmg)** (macOS 11 ou plus récent, Apple Silicon et Intel), avec 14 jours d'essai gratuit.

Ouvrez le DMG et glissez Branch dans Applications. L'appli est signée et notarisée par Apple.

## Acheter

Une licence (9,99 €, achat unique) s'achète depuis l'appli et s'active sur 2 Mac. Pour retrouver votre clé ou changer de Mac : [portail client](https://polar.sh/hgconnect/portal).
